# 两台 Apple Silicon Mac 远程连接测试

适用于 AntifyBot v1.5.0-rc.1。M1、M5 使用相同的 `macOS-arm64` 安装包。安装前通过旧版托盘菜单「退出」，再替换应用；关闭窗口只会收进托盘。

本版包含中转设置、在线状态、文字 / 单文件 / 多文件收发、自动重连、离线补收和持久化去重。文件夹共享继续使用原有局域网传输，不经过中转。

## 1. 接通服务器

若已有 HTTPS 域名，直接在客户端配置该地址。

若服务器目前只监听 `127.0.0.1:53319`，在**两台 Mac 各自**打开终端并建立 SSH 隧道：

```bash
ssh -o ExitOnForwardFailure=yes -N \
  -L 127.0.0.1:53320:127.0.0.1:53319 用户名@服务器IP
```

保持该终端运行。每台 Mac 都需要已经获准登录服务器的 SSH 身份；设备令牌不能代替 SSH 登录凭证。

在另一个终端检查：

```bash
curl http://127.0.0.1:53320/health
```

返回 `{"ok":true,"service":"antify-relay",...}` 后继续。

## 2. 配置客户端

打开「设置 → 远程连接」：

1. 勾选「启用中转服务」。
2. 服务器地址填写 `http://127.0.0.1:53320`。
3. M1 填写设备 A 的令牌，M5 填写设备 B 的令牌。**不要在两台电脑填写同一个令牌。**
4. 点击「保存并连接」，等待「已连接 · 设备身份：desktop-a / desktop-b」。

令牌由服务端管理员提供。客户端只将凭证保存在本机配置目录的 `relay.json` 中；macOS 文件权限为 0600，不写入浏览器 localStorage，也不随安装包分发。再次修改设置时，令牌输入框留空表示保留原令牌。

连接后，侧栏会出现标注「中转」的设备。对方即使同时通过局域网被发现，也会作为单独的局域网会话显示；测试时请选择「中转」会话。

## 3. 验收

| 测试 | 预期 |
| --- | --- |
| M1 发文字，M5 回复 | 双方会话显示正文，出站状态最终为「已送达」 |
| 通过文件按钮或拖拽发送图片、普通文件 | 对方自动下载并验证 SHA-256，显示文件卡片，可定位文件 |
| 退出 M5，M1 继续发文字或文件 | M1 显示「服务端已接收，等待对方保存」 |
| 重启 M5 | 自动补收，M1 状态更新为「已送达」 |
| 中断并重新建立 SSH 隧道 | 自动重连；本地待发送消息继续发送，已保存消息不重复显示 |
| 重启两端应用 | 配置、聊天记录、待发送消息保留 |

文件默认单个不超过 100 MiB、服务端保留 24 小时；消息默认保留 7 天。下载保存在当前接收目录的 `Relay-<标识>/<消息 UUID>/原文件名` 下，避免同名覆盖。中转文件首次下载失败会重试，暂不支持按字节断点续传。

「已送达」表示接收客户端已经保存消息；本版中转接收文件在下载和校验完成后确认，不表示用户已读。只有服务端已接收时，状态仍显示等待对方保存。

## 排查

- 连接失败：先检查本机 `/health`。隧道必须保持运行，服务器地址应填本机隧道地址。
- 401 / 握手失败：核对设备令牌，移除误粘贴的引号。令牌已被撤销时需管理员重新提供。
- 看不到对方：确认两端使用不同令牌，稍等约 5 秒更新设备状态。
- 文件发送失败：确认原文件仍存在、大小不超过 100 MiB，再点击消息下方「重试」。
- 本机排查多实例：可通过 `ANTIFY_CONFIG_DIR=/独立配置目录` 启动独立配置，避免多个实例共用身份与数据库。正常两台电脑测试不需要此设置。

该版本为远程连接测试版，服务端凭证和 SSH 密钥均不包含在公开安装包中。
